# Cobalt Lab

コバルト錯体の構造を動かして考える、高校化学の学習アプリです。

## 公開アプリ

https://easy-person.github.io/Cobalt-Lab/

## できること

- 八面体形・三角柱形・平面六角形への配位子の配置
- 配置の記録と構造ごとの比較、360°の回転・傾き
- NH₃と二座配位子enを自由な順番で配置し、左右で鏡像を比較
- 配置を1つ戻す操作と考察ノートの保存・ダウンロード

## ファイル

- `index.html`：画面の構成
- `style.css`：見た目とスマートフォン向けのレイアウト
- `app.js`：配置・回転・記録などの動作

ビルドやインストールは不要です。GitHub Pagesは `main` ブランチのルートを公開します。これらのファイルを更新すると公開サイトにも反映されます。

記録した配置と考察ノートは使用したブラウザのlocalStorageに保存されます。GitHubやほかの利用者には送信されません。端末間の同期はありません。鏡像画面の作成中の配置はページを再読み込みするとリセットされます。

構造図は配位位置と接続を示す模式図で、実際の結合長・結合角を再現するものではありません。
